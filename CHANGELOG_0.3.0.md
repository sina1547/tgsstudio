# SINA TGS Studio 0.3.0 — Pro Editor Foundation

## Included
- Immersive editor workspace: system status/navigation bars are hidden while editing and restored when leaving the editor.
- The editor canvas now uses the full available display area instead of reserving system-bar padding.
- Debounced document auto-save after editing activity, with visible failure feedback; lifecycle stop-save remains as a second safety net.
- Android version metadata advanced to 0.3.0 (versionCode 3).

## Not included yet
This foundation release does not claim MP4/GIF/WebM export, raster image layers, live editable typography, audio tracks, or a full graph editor. Those require dedicated document/renderer work and regression tests.
