# TGS Studio 0.35.0

## Properties inspector
- Reorganized the inspector into focused Transform, Appearance, Shape, Animation, Effects, and Path/Mask categories.
- Replaced property-panel sliders with numeric fields and stepper controls.
- Fixed rectangle roundness lookup and exposed nested shape properties in the Animation section.
- Improved gradient editing with a visible stop preview, per-stop color/position controls, add/remove stop actions, linear/radial modes, and responsive coordinate fields.
- Made the color picker scrollable and fixed multi-digit RGBA editing.

## Composition canvas
- Added Canvas size to the editor overflow menu.
- Added width/height editing with optional aspect-ratio lock.
- Canvas dimensions are document-level, undoable, and affect exports.
